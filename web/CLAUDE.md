# Portails web Daba (React)

Référence : cahier des charges §4 (portail grossiste), §5 (portail grand client), §6 (PWA hanout).

- React 19 + shadcn/ui + Tailwind CSS 4. Portails : grossiste, grand client, admin, et PWA hanout (ouverte depuis un lien SMS signé, connexion OTP sans mot de passe).
- Langues : darija (arabe et latin), arabe (RTL), français. Mise en page compatible RTL (propriétés logiques CSS), aucun texte en dur.
- Portail grand client : données agrégées et anonymisées uniquement, aucune donnée nominative sur hanouts ou ambulants (CNDP, §5.4).
- Le contrat d'API `../api/openapi.yaml` se lit, il ne se modifie pas ici : demander le changement côté back-end.
